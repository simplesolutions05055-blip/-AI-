## 4. הסרת Twilio

**נמחק:** `_shared/twilio.ts` (193 שורות), `twilio-webhook/` (230), חבילת `twilio` מ-npm (אפס ייבואים בכל הריפו), בלוק `[functions.twilio-webhook]` ב-`config.toml`, `docs/מדריך-הפעלת-twilio.md`.

**גם מפרודקשן:** `supabase functions delete twilio-webhook`.

**הוסר קוד מת:** הענף `whatsappProvider() !== 'smartsend'` ב-`conversation-maintenance` — תמיד `false`, כלומר `sendText` מעולם לא רץ שם. ההסרה שומרת התנהגות מדויקת.

**הוקשח:** `.twilio.com` הוסר משתי רשימות ההיתר של SSRF.

**פרטיות:** `PrivacyPolicyPage.tsx` הצהיר בפני משתמשים ש-Twilio מעבד את הודעות ה-WhatsApp שלהם. לא נכון מאז המעבר. עודכן ל-Smart Send.

## 5. באג אמיתי — שליחה שנדחתה נרשמה כנמסרה

נמצא תוך כדי טיפול ב-`delivery_status`.

שני מסלולי השליחה של Smart Send ספרו כל `HTTP 200` כהצלחה וזרקו את גוף התשובה. Smart Send מחזירה envelope עם `success` — כלומר **שליחה שנדחתה והגיעה כ-`200 {"success":false}` נרשמה ב-`messages` כאילו המשתמש קיבל אותה**. ואין קבלת מסירה שתסתור, אז זה בלתי ניתן לגילוי.

`assertAccepted` מפיל את אלה. **צר בכוונה:** רק `success === false` מפורש; גוף שאינו JSON או בלי השדה מתנהג כמו קודם, כדי לא להתחיל לדחות שליחות חיות.

**הוכחה שהבדיקות תופסות** — ביטול זמני של התיקון:
```
FAILED | 4 passed | 2 failed
```

## 6. `delivery_status` — עמודה בלי כותב

מיגרציה `20260818160000` נכתבה כדי שתשובה שלא הגיעה תשאיר עקבות. הכותב היחיד היה `recordDeliveryStatus` ב-`twilio-webhook` — **שישב מאחורי `if (retired) return 410` והיה בלתי ניתן להגעה מאז המעבר ל-Smart Send.**

נבדק ב-`HEAD` לפני המחיקה: הפונקציה כבר הייתה מתה. לא נשברה על ידי — כבר הייתה שבורה.

Smart Send לא מספקת קבלות מסירה **ולא מחזירה message id**, אז אי אפשר לשחזר את ההתנהגות. במקום להשאיר עמודה מתה, `sendOut` רושם את מה שבאמת ידוע: `sent` (ה-gateway קיבל) / `failed` (השליחה נכשלה) / `NULL` (לא עבר gateway). שורות ה-`failed` ממלאות את `messages_delivery_failed_idx`.

## 7. `twilio_message_sid` → `message_key`

### בחירת השם

הדרישה הייתה שם ניטרלי לספק. הסיבה עמוקה יותר מהעדפה — **העמודה לא מחזיקה מזהה של ספק:**

| מתי | הערך |
|---|---|
| נכנס | מזהה אמיתי של Smart Send |
| יוצא אמיתי | `smartsend-<uuid>` — אנחנו מייצרים |
| סימולטור | `sim-<uuid>` |
| כשל | `undelivered-<uuid>` |

בשלושה מארבעה מקרים זה לא מזהה של אף ספק, אז `provider_message_id` היה שקר **חדש**. התפקיד האמיתי: מפתח ייחודי ל-idempotency מול שליחות חוזרות ולבדיקת "זו עדיין ההודעה האחרונה".

### למה לא `rename column`

**גילוי קריטי:** הפונקציות בפרודקשן נפרסו לאחרונה ב-**2026-09-02 18:21** — לפני כל התיקונים. מיגרציות ופונקציות נפרסות בשתי פקודות נפרדות. `rename` היה משאיר את הקוד החי כותב לעמודה שלא קיימת — **כל הודעה נכנסת נופלת, בלי retry**.

### expand/contract

**שלב 1** (`20260903150000`) — עמודה חדשה, backfill, unique index, וטריגר שמסנכרן את שתי העמודות כדי שקוד ישן וחדש ירוצו במקביל.
**שלב 2** — 29 הפניות ב-6 קבצים, ואז `functions deploy`.
**שלב 3** (`20260903160000`) — מחיקת הטריגר והעמודה הישנה, עם **guard שמסרב למחוק אם יש פער** בין העמודות.

### אימות לפני נגיעה בפרודקשן

הרצתי את המיגרציות **מול הסכימה האמיתית בתוך טרנזקציה שהתגלגלה אחורה**:

```

old-style insert  -> twilio_message_sid=dryrun-old-key  message_key=dryrun-old-key
new-style insert  -> twilio_message_sid=dryrun-new-key  message_key=dryrun-new-key
no-key insert     -> works (conversation-maintenance path)
duplicate         -> rejected
```

אחרי ROLLBACK אומת: `message_key: 0`, אפס שורות בדיקה דלפו.

**מצב סופי:** 1008 שורות עם `message_key`, העמודה הישנה נעלמה, טריגר הוסר, unique index קיים.

## 12. מה לא נעשה — ולמה

**קבלות מסירה מ-Smart Send.** אפשר לדעת ש*נשלח*, אי אפשר לדעת ש*הגיע*. צריך מהספק **גם** webhook סטטוס **וגם** `messageId` בתשובת השליחה — בלי השני אין למה לקשר את הראשון. פנייה לספק, לא קוד.

**`google-auth-config`** — פונקציה שנפרסה ולא קיימת בריפו (38 נפרסו מול 37 בריפו). לא קשורה לעבודה הזו ולא ידוע מה משתמש בה. לא נגעתי.

**ענף ה-Lambda של `render-pdf`** — רץ רק על Vercel ומשתמש בבינארי הארוז. מקומית נבדק Chrome מקומי. שווה להפיק PDF אחד לאימות.

**מיגרציות שכבר רצו** — לא נערכו. שינויים נעשו במיגרציות חדשות בלבד.

**מסמכי היסטוריה ב-`docs/`** — נמחק רק מדריך ההפעלה של Twilio, שהיה מדריך תפעולי פעיל ומטעה. תיעודי סשנים נשארו כארכיון.
