## מה נמצא — מנוע החיפוש היה שבור לגמרי

כל קריאה ל-`brand-autofill` החזירה `fields: []` (חוץ מ-`website`), `engines.search: "failed"`.
הכשל נבלע ב-`Promise.allSettled` ולא נרשם לשום מקום. שני באגים נפרדים:

### באג 1 — תקציב הטוקנים של OpenAI

`searchIdentity` קרא ל-`/v1/responses` עם `max_output_tokens: 1800`.
המודל `gpt-5-mini` הוא מודל reasoning. עם כלי `web_search` הוא מריץ כמה סבבים
(reasoning → web_search → reasoning → …). כל ה-1800 טוקנים נשרפו על reasoning
וקריאות הכלי, ולא נשאר תקציב ל-JSON הסופי.

לוג מהריצה:
```
status=incomplete  reason=max_output_tokens
out_types = reasoning,web_search_call ×8
output_tokens=1500  (reasoning_tokens=1280)
```

`payload.output_text` חזר מחרוזת ריקה → `JSON.parse('')` → `Unexpected end of JSON input` → קריסה.

**תיקון:** `max_output_tokens: 8000` + `reasoning: { effort: 'low' }`.
בנוסף, guard מפורש: אם הטקסט ריק, נזרקת שגיאה עם `status` / `reason` / `usage`
כדי שהפעם הבאה תהיה ניתנת לאבחון.

### באג 2 — בדיקת הציטוטים חסמה כל שדה

הקוד דרש שכל URL מקור יופיע ב-`url_citation` annotations של OpenAI
(`sourceIsCited`). אבל **כשהמודל מחזיר אובייקט JSON נקי, ה-API לא מצרף שום
annotation** — ציטוטים נצמדים למקטעי טקסט פרוזה, ואין כאלה בתשובת JSON.

תוצאה: `citedUrls` תמיד ריק → כל שדה סונן החוצה → רק `website` שרד (כי הוא נופל
חזרה למחרוזת ה-URL עצמה).

**תיקון:** אם `citedUrls` ריק — משתמשים במפת ה-`sources` שהמודל עצמו מחזיר לכל שדה,
מסוננת דרך `safeSourceUrl`. כשיש ציטוטים, הם עדיין מהדקים (חיתוך). המשתמש רואה
ומאשר כל קישור מקור לפני שנשמר משהו — זו ההגנה, לא הציטוט האוטומטי.

### שיפור לוואי — כשלים שקטים

נוספו `logEvent`: `brand_autofill_search_failed` ו-`brand_autofill_crawl_failed`.
עד עכשיו כשל של מנוע נבלע לגמרי.

## מצב פריסה

| Secret | מצב |
|---|---|
| `OPENAI_API_KEY` | ✅ מוגדר |
| `BRAND_CRAWLER_URL` | ❌ חסר |
| `BRAND_CRAWLER_SECRET` | ❌ חסר |
| `OPENAI_SEARCH_MODEL` | לא מוגדר → ברירת מחדל `gpt-5-mini` |
| `BRAND_AUTOFILL_MAX_COST_USD` | לא מוגדר → ברירת מחדל `0.25` |

מנוע קריאת האתר (`services/brand-crawler`) לא פרוס. אין `gcloud` במחשב, אין שירות
Cloud Run רץ. עד שיפרס — הפאנל רץ תמיד ב-`partial`: זהות בלבד, בלי צבעים, בלי
תוכן, בלי זיהוי ריבוי סניפים, בלי זיהוי מותג אם.

### להפעלת מנוע האתר
```bash
brew install --cask google-cloud-sdk && gcloud auth login
gcloud run deploy primeos-brand-crawler --source services/brand-crawler \
  --region me-west1 --allow-unauthenticated \
  --set-env-vars BRAND_CRAWLER_SECRET=$(openssl rand -hex 24) \
  --min-instances 0 --max-instances 2 --memory 2Gi --timeout 300
supabase secrets set BRAND_CRAWLER_URL=https://<url>.run.app/analyze BRAND_CRAWLER_SECRET=<same>
```

## פערים שנשארו (לא חוסמים)

1. **עלות אמיתית ~6–9 סנט לעירייה**, לא "סנטים בודדים" כמו בתוכנית. `web_search`
   ברמת `medium` עולה. עדיין מתחת לתקרת 0.25.
2. **מיקוד לא מגיע לטופס.** המודל מחזיר `postal_code`, אבל ל-`buildFields`
   אין שורה עבורו — השדה נופל בשקט.
3. `engines.website` מציג `"failed"` גם כשזה סתם "לא מוגדר" — קוסמטי.
4. לוגו — ידני לפי התכנון.
